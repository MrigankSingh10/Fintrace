# Finance Tracker

A privacy-focused Android expense tracker that automatically categorizes
transactions from banking SMS messages and helps visualize monthly spending.

## Features

- Automatic transaction detection from SMS
- Needs / Wants / Investment categorization
- Credit and debit tracking
- Monthly expense dashboard
- Payment-method tracking
- Local Room database
- No external account credentials required
