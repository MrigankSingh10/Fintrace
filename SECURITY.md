# Security Policy

## Supported Versions

Only the latest release is currently supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security issue, please report it privately to:

mrigank2303239@gmail.com

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The affected app version
- Any relevant screenshots or logs

I will review the report and address confirmed vulnerabilities as appropriate.
